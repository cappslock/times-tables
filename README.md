# Times Table Flash Cards

A small game for learning the 1–10 times tables by filling in the table, one flash card at a time.

- Answer a card to fill its square (and its mirror: 7 × 6 fills 6 × 7 too).
- **Skip** picks another card, easy facts first: ×1, ×2, ×5, ×10 → ×9 → squares → ×3, ×4 → ×6, ×7, ×8.
- Tap any square to try that card, or tap a blue header number to practise that table in order.
- **💡 Hint** builds the answer from squares you already know.
- Filled squares slowly fade as they come due for review, and a correct review makes them bold again.
- Celebrations for a square, a finished row, and the whole table.

Progress is saved in the browser on each device. Nothing is sent anywhere.

## Run locally

```bash
python3 -m http.server 8123
```

Then open http://localhost:8123.
